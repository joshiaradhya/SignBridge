# Human sign artwork and complete foundations courses

## What will change
- Replace the robotic fallback diagrams in Learn and Practice with warm, human-style instructional hand artwork.
- Redesign every existing sign image, including the eight current references, so each one is clearer, more appealing, and easier to learn from with a consistent human-style teaching illustration.
- Add every letter A–Z and every number 0–9 to both the ASL and ISL Alphabet & Numbers courses.
- Give each new entry its own handshape, palm orientation, movement, step-by-step notes, and common-mistake guidance.

## Visual approach
- Draw natural hands with articulated palms, fingers, wrists, skin shading, nails, joint creases, and clear directional arrows.
- Show one hand for ASL and two hands for ISL where required, with large labels and an uncluttered teaching frame.
- Preserve the current 4:3 media size so lesson and practice layouts remain stable.

## Technical details
- Expand the illustration parser so alphabet and number entries map to explicit finger poses rather than loose keyword guesses.
- Add the missing course rows through a database migration, updating the few existing partial rows rather than duplicating them.
- Keep the Learn area image-and-text based; no video lectures will be added.
- Verify the data counts, current app build, and rendered lesson/practice screens after implementation.
